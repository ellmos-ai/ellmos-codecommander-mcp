1. PRODUCT POSITIONING & VALUE PROPOSITION
------------------------------------------------------------------------------
ellmos-codecommander-mcp is the developer-focused Model Context Protocol (MCP)
server providing 23 specialized tools for code intelligence, AST extraction,
Python structural refactoring, syntax and indentation validation, runtime import
diagnostics, JSON repair, encoding recovery, format conversion, file diffing,
and regex evaluation.

Designed specifically for AI coding assistants (Claude Desktop, Claude Code,
Cursor, Windsurf, Codex, Antigravity), CodeCommander acts as the precision
code-intelligence counterpart to FileCommander in the ellmos MCP family.

Key Differentiators:
- 23 developer-tailored MCP tools operating over standard local stdio JSON-RPC.
- 100% Local-First & Zero-Egress: Pure offline operation without network calls or telemetry.
- Safe AST refactoring: Preview-first diff generation before disk mutations, with automatic .bak backups.
- Python runtime import diagnostics executing in isolated, timeout-bounded subprocesses.
- Encoding recovery repairing 27+ Mojibake patterns and 70+ German umlaut corruptions without data loss.
- Universal format conversions across JSON, CSV, INI, YAML, TOML, XML, and TOON.
- Dynamic multi-language support (i18n) across 6 languages (EN, DE, ES, ZH, JA, RU).

2. TARGET AUDIENCE & STAKEHOLDER PERSONAS
------------------------------------------------------------------------------
[PERSONA-01] ([PERSONA-1]) Autonomous AI Coding Agents & LLM Pair-Programmers
- Profile: Agents like Claude Code, Antigravity, Codex, Cursor, and Windsurf performing code refactoring.
- Pain Point: LLMs generating broken code chunks, losing indentation, causing syntax errors, or hallucinating imports.
- Solution: AST class/method extraction (cc_extract_classes, cc_analyze_methods), structural edits with unified diffs (cc_python_structural_edit), and PEP 8 import organizing (cc_organize_imports).

[PERSONA-02] ([PERSONA-2]) Full-Stack & Python/TypeScript Software Engineers
- Profile: Developers building complex applications requiring accurate AST analysis and fast format transitions.
- Pain Point: Manual file conversions across JSON/YAML/TOML/TOON/XML and tedious import dependency tracking.
- Solution: Deterministic multi-format converter (cc_convert_format), import diagnostics (cc_diagnose_imports, cc_runtime_import_diagnose), and regex testing (cc_regex_test).

[PERSONA-03] ([PERSONA-3]) Security, QA & Code Governance Engineers
- Profile: Security auditors and compliance officers enforcing local-first, unprivileged tool execution.
- Pain Point: Risk of accidental code corruption, secret leakage, or uncontrolled elevation by AI agent tools.
- Solution: Zero-Egress architecture, unprivileged user mode (RunAsInvoker), mandatory .bak backups prior to write operations, and isolated subprocess execution.

[PERSONA-04] ([PERSONA-4]) Open-Source Ecosystem Architects & MCP Tool Developers
- Profile: Maintainers building and cataloging MCP servers across Glama, Smithery, and GitHub.
- Pain Point: Unsynchronized tool manifests, missing third-party license notices, and inconsistent metadata.
- Solution: 100% parity across package.json, server.json, glama.json, smithery.yaml, llms.txt, and automated contract test validation.

5. GOVERNANCE & RUNTIME INVARIANTS
------------------------------------------------------------------------------
- INV-LOCAL-01: 100% Local-First & Zero-Egress Stdio Protocol
  All communications take place strictly over local standard I/O (stdio); no network
  calls, no analytics, no external tracking.
- INV-SEC-02: Unprivileged User-Space Execution
  Executes as an unprivileged process (RunAsInvoker) without requesting or requiring
  administrative elevation or root permissions.
- INV-PREV-03: Preview-First & Dry-Run Safety
  Structural code transformations default to non-mutating preview mode with unified diffs,
  preventing unintended file changes.
- INV-BAK-04: Mandatory Pre-Mutation Backups
  File-modifying tools automatically create timestamped `.bak` backup copies before writing
  any changes to disk.
- INV-ISOL-05: Isolated Subprocess Execution
  Runtime Python import diagnosis (cc_runtime_import_diagnose) executes in temporary,
  isolated child processes with strict execution timeouts.
- INV-GATE-06: Explicit Language-Gate Validation
  Python-specific tools reject non-Python files explicitly; JS/TS analysis is read-only
  and dependency-free.
- INV-ENC-07: Non-Destructive Encoding & Umlaut Repair
  Repairs 27+ Mojibake patterns, 70+ German umlaut patterns, and strips BOM/NUL bytes
  without corrupting valid binary or text data.
- INV-FMT-08: Deterministic Multi-Format Conversions
  Lossless roundtrip conversion support for JSON, YAML, TOML, XML, CSV, INI, and TOON
  with strict schema and type preservation.
- INV-I18N-09: Runtime Multi-Language Support
  Dynamic runtime language switching across English, German, Spanish, Chinese, Japanese,
  and Russian via cc_set_language and cc_get_language.
- INV-SLA-10: 48h Security Response SLA & Multi-OS CI
  Multi-OS GitHub Actions CI (Ubuntu, Windows, macOS across Node 20, 22, 24) and public
  48h response / 5-day triage commitment.
