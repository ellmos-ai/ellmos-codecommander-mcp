## Level 1 SBOM Invariant Verification (Stand: 2026-10-09)

All 10 architectural and runtime governance invariants are confirmed:
- INV-LOCAL-01: Zero-Egress Privacy (100% offline local stdio JSON-RPC transport; zero telemetry, zero analytics, zero external network egress)
- INV-SEC-02: Unprivileged Execution (Runs strictly in user space as RunAsInvoker; zero administrative elevation or root privileges requested)
- INV-PREV-03: Preview Safety (Structural Python edits default to non-mutating preview mode emitting unified diffs without file writes)
- INV-BAK-04: Mandatory Backups (In-place file mutations automatically generate timestamped .bak backup copies before writing to disk)
- INV-ISOL-05: Subprocess Isolation (Runtime Python import diagnostics execute in isolated child processes with hard timeouts)
- INV-GATE-06: Explicit Language Gates (Python-only tools explicitly reject non-.py files; JS/TS analysis is read-only and dependency-free)
- INV-ENC-07: Non-Destructive Encoding (Repairs 27+ Mojibake patterns, 70+ German umlaut corruptions, and normalizes UTF-8 without data loss)
- INV-FMT-08: Lossless Format Parity (Roundtrip format conversion across JSON, CSV, INI, YAML, TOML, XML, and TOON preserving types and schemas)
- INV-I18N-09: Dynamic Multi-Language (Full runtime i18n across 6 languages EN, DE, ES, ZH, JA, RU via cc_set_language and cc_get_language)
- INV-SLA-10: 48h Response / 5d Triage / 30d Remediation SLA (Multi-OS CI Ubuntu, Windows, macOS across Node 20, 22, 24, binding 48h vulnerability response SLA, 5d triage, and 30d remediation SLA)
